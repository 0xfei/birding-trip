# 本行程断言

只对**这一趟**成立的期望值。通用检查在 `engine/verify.py` 里，
不要把行程特有的数字写进那边——换个行程就全错了。

断言是 Python 表达式，可用的变量：

| 变量 | 含义 |
|---|---|
| `n_region` | eBird 地区名录条数（含非种级分类单元）|
| `n_species` | 其中种级的数量 |
| `n_endemic` | 特有种数（eBird 全地区倒排判定）|
| `n_lifer` | 生涯新种数（目的地有、母语区无）|
| `n_days` / `n_blocks` / `n_sites` | 行程天数 / 时段数 / 点位数 |

## 断言表

| 断言 | 说明 |
|---|---|
| `n_endemic == 35` | 斯里兰卡特有种公认 35 种。eBird 原生判定独立算出同一个数，并与用户提供的名单比对过——名单里的 3 处差异全部是名单自身的缺陷（红背啄木鸟误指南美种、棕鸫鹛误指印度种、林鵙有错字），不是判定错 |
| `n_species >= 470` | 地区名录不应显著缩水。雀跃第三方名录 470 种，是 eBird 的严格子集 |
| `n_days == 10` | 02-03 ~ 02-12 共 10 天 |
| `n_blocks == 25` | 迁移自原项目的 25 个时段，改行程时要同步改这里 |
| `n_sites == 11` | 11 个取数点位 |
| `n_lifer >= 120` | 中国无记录的种。原项目按雀跃口径得 69 种，eBird 口径更宽（含更多迷鸟与海鸟），两者不可直接比 |

## 已裁决的第三方分歧

第三方与 eBird 不一致、且**已经人工看过**的，记在这里，
下次出现同样的分歧不必重新想一遍。

| 分歧 | 裁决 | 日期 |
|---|---|---|
| 雀跃有 `Corvus levaillantii`（丛林鸦），eBird 分类查无此名 | 以 eBird 为准，不入清单。该学名在 eBird 体系下已被归并 | 2026-10-20 |
| 雀跃有 `Curruca althaea`（休氏白喉林莺），eBird 分类查无此名 | 同上 | 2026-10-20 |
| eBird 比雀跃多 6 种（苍雨燕、布氏白腰雨燕、白燕鸥、黄嘴河燕鸥、灰头椋鸟、黑喉石䳭）| 以 eBird 为准，已在清单中 | 2026-10-20 |
| IOC 与 eBird 英文名实质不同的 20 种 | **显示用 IOC（老牌图鉴常用名）**，因为当地鸟导用图鉴；两种叫法都进反向索引，报鸟时对方听不懂就换另一个说 | 2026-10-20 |
| 用户名单的「红背啄木鸟」解析到 Crimson-mantled Woodpecker（南美种）| 名单笔误，正确的是绯红背啄木鸟 Crimson-backed Flameback | 2026-10-20 |
| 用户名单的「棕鸫鹛」解析到 Rufous Babbler（印度种）| 名单笔误，正确的是橙嘴鸫鹛 Orange-billed Babbler | 2026-10-20 |

## 模型校准留痕

**不静默调参**——改了参数必须在这里写明改前改后与理由。

| 日期 | 改动 | 理由 |
|---|---|---|
| 2026-10-21 | `ref_hours` 由 4.0 改为 8.0 | 核对 6 个走兜底的时长后发现**改时长不改变预测**：当量封顶 1.0，而 3h × 顶级鸟导 1.6 = 1.2 已撞上限，11.5h 算出 4.6 也撞上限——半天与全天被当成一样。`ref_hours` 代表「一个 eBird 观鸟日折合我们多少小时」，而 eBird 的观鸟日是全站所有观察者的并集，覆盖量至少相当于一整天，取 4 偏小。改为 8 后撞上限的时段由 7/25 降到 4/25，3h 鸟导时段当量 1.00→0.60，时长重新起作用。预测 192→185 |
| 2026-10-20 | 当量上限 `E_CAP` 由 2.0 改为 1.0，且封顶作用在**最终当量**上 | 泰国 2 天 demo 预测出 231 种，暴露高估：原先把 6h 鸟导时段折算成 2.02 个「观鸟日」，而一个观鸟日是该点位当天**所有观察者的清单并集**，一队人不可能超过它。斯里兰卡 215→192 |

**参考行程实测对照**（用来判断模型偏向，不用来自动调参）：

| 参考 | 天数 | 实测种数 | 本模型对本行程的预测 |
|---|---:|---:|---:|
| Birdquest 2025-12 | 12 | 230 | 192（10 天）|
