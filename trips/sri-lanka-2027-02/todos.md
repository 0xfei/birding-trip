## ② 每位鸟导都走一遍

模板。每段鸟导各走一遍，不要只对第一位说。

| 级别 | 事项 | 为什么 |
|:-:|---|---|
| 下单时 | **用英文名 + 学名**确认目标种，不要用中文名 | 中文名各家不一。英文名直接从目标清单第五节复制，别凭记忆写 |
| 下单时 | 说清本段是「要鸟不要大兽」还是反过来，以及愿不愿为单一目标久等 | 这决定他整天怎么开车、怎么走，比给他一张长清单重要 |
| 下单时 | 问能否提前请追踪员找**白天的 roost**（鸮类与蛙口夜鹰） | [BQ] 实测这是夜鸟成败的关键，而且是点位人脉问题、不是水平问题 |
| 下单时 | 问夜探除了鸟还看不看两栖、哺乳与昆虫 | 决定夜探的内容与要不要自带手电 |
| 到场前一天 | 确认次日出发时刻与集合点，**把具体钟点说出来** | [BQ]／[SH] 都踩过「司机按自己的习惯发车」的坑 |
| 见面头 5 分钟 | 把本段的 🔴／🟠 难鸟**逐个念一遍**，问他今年见过没有 | 比递一张长清单有效得多，也能立刻看出他熟不熟这一带 |
| 见面头 5 分钟 | 问**哪些老点已经失效**（砍树、洪水、修路） | [BQ] 实测 Tissa 的渔鸮林斑被砍、Victoria Park 的地鸫移位，都是这么发现的 |
| 见面头 5 分钟 | 问今天的天气窗口；若午后有雷雨就把重点全压到上午 | [BQ] 实测雷阵雨一到鸟况立刻归零 |
| 每天收工时 | 对一遍**今天拿到了什么、还缺什么**，让他明天定向补 | 02-10 早上那个补漏场的全部价值就在这里 |
| 每天收工时 | 不确定的种当场翻照片定下来，别留到回国 | [BQ] 有两种是回国后请专家看照片才定的——那就补不了了 |
