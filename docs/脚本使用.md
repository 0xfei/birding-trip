# 脚本使用

全部用 `python3 -I`（隔离模式，避免从数据目录加载同名模块）。
`<trip>` 形如 `trips/sri-lanka-2027-02`。

## 一键

| 命令 | 做什么 |
|---|---|
| `engine/build.py --trip <trip>` | 重建全部产出（约 1.4 秒，不取数）|
| `engine/build.py --trip <trip> --fetch --rate 25` | 连带重新取数（慢，会被限流）|
| `engine/verify.py --trip <trip> [-v]` | 全链路校验，任一项失败非零退出 |
| `engine/doctor.py --trip <trip> --net --determinism` | 排障自检 |

**改了生成器一定走 `build.py`**：校验只读 `.md`，发现不了生成器崩了。

## 全局参考数据（所有行程共用，一次性）

| 命令 | 产出 |
|---|---|
| `engine/refdata/fetch_taxonomy.py` | eBird 分类骨干 11,167 种（物种主键来源）|
| `engine/refdata/fetch_ioc.py` | IOC 中文名字典 11,227 种 |
| `engine/endemism.py --world-cache` | 253 个地区名录倒排（特有种判定）|

都带 `--force` / `--report`。`--world-cache` 可断点续抓。

## 取数

```bash
engine/sources/ebird.py --trip <trip> [--step spplist|hotspots|freq|all] [--rate N] [--report]
```

- `spplist` —— 地区名录 + 母语区名录（生涯新种基准）
- `hotspots` —— 每个点位用哪些 locId（钉死的直接用，没钉的按半径搜）
- `freq` —— 核心产出，请求数 = 热点数 × 取样天数，**会被限流**
- `--report` —— 离线，只读缓存

第三方（**只比对，不覆盖 eBird**）：

```bash
engine/sources/thirdparty/gbif.py --trip <trip>                  # 鸟类 double check
engine/sources/thirdparty/gbif.py --trip <trip> --taxa Mammalia  # 非鸟类群
```

非鸟类群可选 `Mammalia` / `Reptilia` / `Amphibia`。
**这一层没有 eBird 数据源**，不计入总种数、不进概率模型。

## 判定与渲染

| 命令 | 产出 |
|---|---|
| `engine/endemism.py --trip <trip> [--compare <名单>]` | 特有种；`--compare` 与一份已有名单比对 |
| `engine/render/species_list.py --trip <trip>` | `01-鸟种清单.md` |
| `engine/render/itinerary.py --trip <trip>` | `02-行程表.md` |
| `engine/render/discrepancy.py --trip <trip>` | `03-第三方分歧.md` |
| `engine/estimate.py --trip <trip>` | `04-预期产出.md` |
| `engine/render/logistics.py --trip <trip>` | `05-行前与物流.md` |

都支持 `-o` 指定输出路径。

## 物料与名字闸门

```bash
engine/materials.py --trip <trip> --add <url|路径>
engine/materials.py --trip <trip> --add-text "..." --label "..."
engine/materials.py --trip <trip> --list
engine/materials.py --trip <trip> --resolve "名字1" "名字2"
```

`--resolve` 是**写进配置前必须过的闸门**。输出每行
`OK\t名字\tcode\t显示名\t学名` 或 `UNRESOLVED\t名字\t\t\t原因`，
有未解析时退出码为 1。**必须带 `--trip`**，否则读不到行程的别名表。

## 查一个名字

```bash
python3 -I engine/taxonomy.py "Sri Lanka Blue-Magpie" "红脸地鹃"
```

不带参数则打印全球中文名覆盖统计。

## 一次性迁移

```bash
python3 -I tools/migrate_sri_lanka.py [--write]
```

把旧 `scripts/` 里硬编码的判断表导成 `trips/<id>/*.md`。
所有数值由 `import` 读出，**不经人工转写**（全局准则 7）。
默认只预览，加 `--write` 才落盘。
