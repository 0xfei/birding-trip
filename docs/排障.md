# 排障

出问题先跑这个：

```bash
python3 -I engine/doctor.py --trip trips/<id> --net
python3 -I engine/doctor.py --trip trips/<id> --determinism
```

它专查**静默故障**——不报错但悄悄给出错结果的那类，每条都给修复命令。

## 这套工具的失败几乎都是静默的

| 症状 | 真实原因 | 处方 |
|---|---|---|
| 某张表的内容全没了 | **表格分隔行解析不了，整表读成空** | 分隔行写成 `\|---\|---\|` 或 `\|:-:\|---\|`。实测 47 条待办曾因 `\|:-:\|` 全部丢失 |
| 频次普遍偏低 | 空清单日被算进了分母 | 分母只数「真的有人观鸟的日子」。实测修正后分母由 56 降到 19–48 |
| 某些种凭空消失、分母偏小 | **eBird 限速响应被当成空数据** | 429 是**纯文本不是 JSON**；已内建退避重试。`doctor` 会报「永久失败的请求数」 |
| 两个点位的频次完全相同 | 半径搜热点**串点** | 在 `sites.md` 里钉死各自的 `locId`。实测出过「公园的频次其实是整个镇区的」 |
| 某点位所有频次都是 0 | 该点位分母为 0 | 检查 `locId` / 坐标；`doctor` 会报出来 |
| 文档停在旧版本但校验全绿 | 生成器崩了，校验读的是旧文件 | **用 `engine/build.py`**，不要只跑单个渲染器 |
| 两次构建产物不同 | 生成器无序遍历 `set` | 一律 `sorted()`；`verify.py` 有专项检查 |
| 断言全部报语法错 | 表格里的反引号没剥掉 | 已修；断言求值前 `strip("`")` |
| 查某个表却拿到另一个表 | 标题**子串匹配**踩到包含关系 | 已改为优先精确匹配。实测「本行程断言」把查「断言」的请求截走了 |
| GBIF 全部返回 0 条 | `urlencode` 没展开列表参数，`month=[2]` 变成 `month=%5B2%5D` | 用 `doseq=True` |
| 非特有种被判成特有 | 全地区名录有地区没取到 | `endemism.py --world-cache` 续抓；`doctor` 会报缺几个地区 |
| 多出一个查不到名字的「特有种」 | `spplist` 会返回**亚种群等非种级分类单元** | 已加种级过滤。实测斯里兰卡返回过 `bkrfla3` |
| 老图鉴叫法被判「查无此名」 | 名字闸门没加载**行程别名表** | `--resolve` 要带 `--trip` |

## eBird 限速

**没有公布的限额，但确实存在且会持续数小时。**

实测：40 分钟内发了约 2500 个请求后，对**每一个**请求返回
`429 Too Many Requests`，等 60 秒不恢复，**隔夜才解除**。

对策：
- `--rate` 控制每分钟请求数，默认 25/min，实测不触发限流；
- 成功的请求全部落盘，**中断零损失**，重跑只补缺口；
- 限速响应会退避重试（最多 4 轮），**永久失败才计数并报出来**。

### 三条看着能降量、实际走不通的路

| 想法 | 为什么不行 |
|---|---|
| `curl --parallel` 并行 | 实测确实快 3 倍（10 个请求 0.95s vs 3.1s），但**瓶颈是配额不是带宽** |
| eBird barchart 接口（一个请求返回整张频次表）| **被 bot 检测挡住**，返回人机验证页而不是 TSV |
| 地区级 `historic`（想用「1 请求/地区/天」替代「1 请求/热点/天」，降量 27 倍）| **死路**：返回里确实带 `locId`，很诱人，但**每种只返回一条记录**（某日 244 条记录 = 244 个不同种），**还原不出各点位的频次** |

结论：老老实实逐热点取，节流 + 缓存 + 可续抓。

## 网络

**`python3 -I` 隔离模式不读代理环境变量，`urllib` 会 DNS 失败。**

所以本项目一律用 `curl` 取数——它会读 `https_proxy`。
需要代理就 `export https_proxy=...` 再跑。

## API key

只从环境变量 `EBIRD_API_KEY` 读，其次读仓库根的 `.ebird_api_key`。
**绝不写进任何生成物，也不经自然语言转述。**
申请：https://ebird.org/api/keygen

`doctor` 会确认 key 存在且有效，但**不打印 key 本身**。

## 强制重抓

缓存是幂等的，删文件即可强制重抓：

```bash
rm trips/<id>/materials/_ebird_cache/hist_<locId>_*.json   # 某个热点的频次
rm -rf trips/<id>/materials/_gbif_cache                    # 全部 GBIF
rm engine/refdata/ebird_taxonomy.json                      # 分类骨干
python3 -I engine/refdata/fetch_ioc.py --force              # IOC 字典
```

损坏的缓存文件会被当成「那天没数据」——`doctor` 的「缓存健康」一节专查这个。

## 确定性自检

```bash
python3 -I engine/doctor.py --trip trips/<id> --determinism
```

重建一次并**逐字节**比对。不一致就是生成器有无序遍历。
